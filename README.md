# Siddur App

An Android Siddur (Jewish prayer book) app.

## Download

Get the latest APK from the [Releases page](https://github.com/mendygreenberg770/Siddur-app/releases/latest).

## Install on Android

1. Download the `.apk` file from the latest release on your Android phone.
2. Open the downloaded file.
3. If prompted, allow your browser or file manager to **install unknown apps**.
4. Tap **Install**.
